# Kuku Promo Prototype

A Streamlit client prototype for finding and reviewing promo segments from uploaded scripts.

## Run locally

Install `requirements.txt`, then run `python -m streamlit run jagan.py`.

The repository does not include screenplay inputs or generated results. Upload a script folder in the app to analyze it. Model API settings are optional; local rules work without a key. Configure secrets only in the hosting service, never in this repository.

## Deploy

Deploy `jagan.py` from this repository with Streamlit Community Cloud.
